图标 (Icons)

本框架集成了 Font Awesome 图标库，您可以使用 v-button 组件的 icon 属性来添加图标。

fa-home
fa-user
fa-cog
fa-heart
fa-star
fa-search
fa-envelope
fa-bell
fa-calendar
fa-image
fa-music
fa-video
fa-lock
fa-unlock
fa-key
fa-power-off

使用方法

在 v-button 组件中使用 icon 属性添加图标：

<v-button icon="fas fa-home">首页</v-button>
<v-button icon="fas fa-user" type="primary">用户</v-button>
<v-button icon="fas fa-cog" circle></v-button>
