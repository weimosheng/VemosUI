主题系统

主题系统是VemosUI的重要组成部分，支持明亮和暗黑两种模式。通过CSS变量实现动态主题切换，所有组件都会自动响应主题变化。

明亮模式 暗黑模式 跟随系统
变量名 描述 明亮模式值 暗黑模式值
--vemos-bg-default 默认背景色 #ffffff #2d3748
--vemos-text-default 默认文字色 #212529 #e2e8f0
--vemos-border-default 默认边框色 #dcdfe6 #4a5568
--vemos-bg-primary 主要背景色 #409EFF #63b3ed
--vemos-text-primary 主要文字色 #ffffff #0c1e35

window.VemosUI.toggleDarkMode(enable)

描述： 切换暗黑模式的开启或关闭状态

参数：

  • enable (boolean) - 是否启用暗黑模式

window.VemosUI.isDarkMode()

描述： 检查当前是否为暗黑模式

返回值： (boolean) 如果当前是暗黑模式则返回 true，否则返回 false

启用暗黑模式 启用明亮模式 检查当前模式 显示当前主题

当前状态将在点击按钮后显示在这里

VemosUI会自动检测用户的系统偏好设置（通过prefers-color-scheme媒体查询）。当用户选择"跟随系统"时，主题会根据系统设置自动调整。

主题设置会保存在localStorage中，确保在页面刷新后仍保持用户的选择。
