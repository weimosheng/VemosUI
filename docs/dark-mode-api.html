VemosUI 暗黑模式 API

VemosUI 提供了灵活的 API 来控制暗黑模式的开启和关闭，以及检测当前主题状态。通过这些 API，你可以轻松地在明亮和暗黑主题之间切换，或者让用户选择跟随系统设置。

API 方法

window.VemosUI.toggleDarkMode(enable)

描述： 切换暗黑模式的开启或关闭状态

参数：

  • enable (boolean) - 是否启用暗黑模式

用法：

// 启用暗黑模式
window.VemosUI.toggleDarkMode(true);

// 关闭暗黑模式（回到明亮模式）
window.VemosUI.toggleDarkMode(false);

window.VemosUI.isDarkMode()

描述： 检查当前是否为暗黑模式

返回值： (boolean) 如果当前是暗黑模式则返回 true，否则返回 false

用法：

// 检查当前是否为暗黑模式
if (window.VemosUI.isDarkMode()) {
  console.log('当前为暗黑模式');
} else {
  console.log('当前为明亮模式');
}

window.VemosUI.toggleTheme(theme)

描述： 更通用的主题切换方法，支持明亮、暗黑和自动（跟随系统）

参数：

  • theme ('light' | 'dark' | 'auto') - 要切换的主题类型

用法：

// 设置为明亮模式
window.VemosUI.toggleTheme('light');

// 设置为暗黑模式
window.VemosUI.toggleTheme('dark');

// 跟随系统设置
window.VemosUI.toggleTheme('auto');

window.VemosUI.getCurrentTheme()

描述： 获取当前的主题设置

返回值： ('light' | 'dark' | 'auto') 当前主题类型

用法：

// 获取当前主题
const currentTheme = window.VemosUI.getCurrentTheme();
console.log('当前主题:', currentTheme);

注意事项

  • 主题设置会保存在 localStorage 中，即使刷新页面也会保持设置
  • toggleDarkMode 是 toggleTheme 的简化版本，专门用于暗黑模式的切换
  • 如果用户选择了"跟随系统"，则会在系统主题发生变化时自动切换
  • 所有的 UI 组件都会自动响应主题变化
