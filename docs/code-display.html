代码展示 (v-code-display)

v-code-display 是一个用于展示代码片段的组件，支持多种编程语言和代码高亮显示。

基本用法

使用code属性指定代码

显示行号

function fibonacci(n) { if (n <= 1) return n; return fibonacci(n - 1) + fibonacci(n - 2); } console.log(fibonacci(10)); // 55

隐藏复制按钮

.container { display: flex; justify-content: center; align-items: center; height: 100vh; background-color: #f0f0f0; }
