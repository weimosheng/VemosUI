代码展示 (v-code-display)

v-code-display 是一个代码高亮展示组件，支持多种编程语言、行号显示和一键复制功能。

基本用法

<!DOCTYPE html> <html> <head> <title>Hello World</title> </head> <body> <h1>Hello World</h1> <p>这是一个简单的HTML页面</p> </body> </html>

显示行号

function greet(name) { return `Hello, ${name}!`; } console.log(greet('World'));

隐藏复制按钮

.container { display: flex; justify-content: center; align-items: center; width: 100%; height: 100vh; }
